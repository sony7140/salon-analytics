# data/ — 익명화 공개 데이터

노트북 4개(`notebooks/`)가 **기본 경로**로 읽는 데이터다. clone 한 뒤 환경변수 없이 노트북을 돌리면 이 파일들을 읽는다.
원본(서울 소재 미용실 1곳의 2025년1월~2026년8월까지 매장 예약 상세 목록, 예약자 관리 데이터, 가게 리포트)에서 식별 정보를 바꾸거나 가리고, 공개하지 않을 컬럼만 뺐다.

## 원본과 다른 점

| 무엇 | 공개본 |
|---|---|
| 고객 이름 칸 (`예약자` · `방문자` · `hands_name` · 핸즈 `고객`) | 가명. 같은 사람은 같은 가명이고, 네이버 마스킹 꼴(`홍*동`)과 이름 첫 글자 구조는 원본과 같다 |
| 디자이너 · 채널 라벨 · 상호 · 지점 · 일부 메뉴명(거래처 브랜드) | 새 이름 · 코드명 (`가온 대표원장` · `알파` · `베타` 등) |
| 전화번호 | 컬럼 없음. 고객 키 `cust_key`(이름 첫 글자 + `\|` + 전화 뒤 4자리)의 뒤 4자리는 원본 번호가 아닌 합성 값이다 |
| 예약번호 | 1부터 시작하는 일련번호 — 이용 일시 순, 같은 시각이면 원래 번호 순. `reservations` 와 `menu_lines` 가 같은 번호를 쓴다 |
| 자유 텍스트 (`요청사항` · `취소사유` · `직원메모`) | 허용 어휘(일반어 · 분류 규칙이 찾는 낱말 · 메뉴명 · 조사·어미) 밖 낱말은 **같은 길이의 자모 기호**(`ㄱ` `ㄲ` `ㄸ` `ㄹ` `ㅃ` `ㅆ` `ㅉ` `ㅌ` `ㅍ` 등)로 가렸다. 같은 낱말은 같은 기호다 (한 글자 낱말은 기호 수가 모자라 기호가 겹칠 수 있다). 전화번호 꼴은 `***-****-****`, 전화 뒤 4자리를 적은 숫자는 `****`. 그 밖의 숫자 · 문장 부호 · 매장 정형 안내문은 그대로다. 문자 종류만 보는 분류(외국어 판정 · 무의미 입력 · 한자 포함)가 바뀌는 4행은 기호 대신 같은 종류의 중립 문자(`힣` · `x` · `丶`)로 채웠다 |
| 뺀 컬럼 | 연락처 · 가게가 고객에게 매긴 판정 · 원본 파일명 · POS(핸즈) 조인 진단과 내부 칸 — 아래. 그 밖의 컬럼은 노트북이 쓰지 않아도 그대로 두었다 |

금액(`paid` · `listed` · `listed_max` · `쿠폰적용금액` · `매장결제금액(B)` · `환불금액` · `line_price` · 단가)과 일시 · 건수는 **원 단위 원본 그대로**다.

### 뺀 컬럼

- `processed/reservations.parquet` (37 → 29) — `전화번호`(연락처) · `블랙리스트등록여부` · `cust_grade`(가게가 고객에게 매긴 판정) ·
  `src_file`(원본 파일명) · `hands_status` · `hands_sales_entered` · `hands_match_level` · `hands_match_ambiguous`(POS 조인 진단 · 입력 상태)
- `processed/hands_all.parquet` (25 → 4) — `상태` · `고객` · `is_naver` · `ym` 만 남겼다. 뺀 21칸은 직원 메모(`메모` — 고객 텍스트 사본 포함) ·
  뜻을 알 수 없는 칸 · POS 내부 칸이다.
- 나머지 파일(`menu_lines` · `price_catalog` · `manual/` 의 CSV 4종)은 컬럼을 빼지 않았다.

## 포함하지 않은 것

- 원본 엑셀 · HTML (네이버 예약자관리 · 핸즈 예약상세 · 월별 리포트) — `data/raw/` 자리다. `build.py` 는 이것이 있어야 돈다.
- 정제 전 데이터와 월별 리포트 집계 — 노트북이 읽지 않는다.

## 원본 분석과 숫자가 다른 곳

- 테이블 컬럼 수를 찍는 줄 (01 · 04 로딩 셀) — 뺀 컬럼 수만큼.
- 03 ②-c2 '기타' 취소사유의 빈도 상위 표현 — 가린 텍스트에서 세므로 가린 낱말이 빠지고 건수가 바뀐다.
  같은 절에서 그 표보다 앞에 있는 ②-c1 2차 분류(15종)는 원본과 행 단위로 같다.
- 03 ②-a3 미분류 요청사항 목록의 한 줄 — 전화 뒤 4자리를 적은 숫자를 가렸다.

나머지 수치(노트북 02 · 03 · 04 의 대조 게이트 22 / 31 / 21 항목 포함)는 원본 분석과 같다.
