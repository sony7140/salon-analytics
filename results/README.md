# 집계 결과

공개 데이터로 실행해 저장된 노트북 산출물 중, 개별 예약·고객 행과 자유 서술 열이 없는 집계표만 복사했다. 모든 CSV는 노트북 산출물과 바이트가 같다.

| 파일 | 내용 | 노트북·절·셀 | 한 행 |
|---|---|---|---|
| [ch_summary.csv](ch_summary.csv) | 유입경로별 예약·매출·첫 방문 고객 재방문 지표 | [03 ①-b](../notebooks/03_유입경로_요청사항_캐파검증_재방문.ipynb) · c16~c18 / 저장 c115 | 유입경로 그룹 |
| [capacity_compare.csv](capacity_compare.csv) | 건수와 가정 A·B 시간 기준 가동률 비교 | [03 ③-b2](../notebooks/03_유입경로_요청사항_캐파검증_재방문.ipynb) · c60 / 저장 c115 | 디자이너 |
| [capacity_slots.csv](capacity_slots.csv) | 예약·미근무·마감·병행·공백 슬롯 수 | [03 ③-d2 · ③-E2](../notebooks/03_유입경로_요청사항_캐파검증_재방문.ipynb) · c70·c78 / 저장 c115 | 가정·관측 기준 × 디자이너 |
| [capacity_observed.csv](capacity_observed.csv) | 관측 표본과 건수 조건화 보정 점유율 | [03 ③-E1](../notebooks/03_유입경로_요청사항_캐파검증_재방문.ipynb) · c77 / 저장 c115 | 디자이너 |
| [capacity_observed_summary.csv](capacity_observed_summary.csv) | 월 추가 수용 가능 범위와 빈 시간의 비교 | [03 ③-E2](../notebooks/03_유입경로_요청사항_캐파검증_재방문.ipynb) · c78 / 저장 c115 | 가정 A·B·관측 기준 |

셀 번호는 노트북 JSON의 0부터 시작하는 위치다. `Unnamed: 0`은 저장된 표의 행 라벨이다. 디자이너명은 공개용 가명이며, `소표본`은 고정된 경고 라벨이다.

가동률·수용 가능 규모는 실제 추가 매출이 아니다. 가정 A·B 결과는 관측 결과와 함께 읽는다. 관측 표본은 늦게 끝난 시술이 빠지는 편향이 있고, 근무일도 완료 예약으로 추정한다. 마감 이후 연장 근무는 별도다. 추가 수용 가능 건수는 공급 측 추정이며 수요 확보를 보장하지 않는다.

03 ②-c2의 가린 텍스트 빈도표는 포함하지 않았다. 해당 빈도는 원본과 다르며 자세한 차이는 [데이터 설명](../data/README.md)에 있다.
